MVC: Model, View, Controller
MVC (Model-View-Controller) is a software architecture pattern that separates an application into three parts:
    Model → Manages data and business logic.
    View → Displays the user interface.
    Controller → Handles requests and coordinates between Model and View.

1. Model
The Model is responsible for interacting with the database.
In your project:
models/
    listing.js
    review.js
    user.js

2. View
The View is what the user sees.
In Express, Views are EJS files.
views/
    listings/
        index.ejs
        show.ejs
        new.ejs

3. Controller
The Controller receives requests from the browser.
Example:
GET /listings

module.exports.updateListing = async (req, res) => {
    const listing = await Listing.findByIdAndUpdate(
        req.params.id,
        { ...req.body.listing },
        { runValidators: true, new: true }
    );

    if (req.file) {
        listing.image = {
            url: req.file.path,
            filename: req.file.filename,
        };
        await listing.save();
    }

    req.flash("success", "Listing updated");
    res.redirect(`/listings/${listing._id}`);
};

What Multer does
Your route:
router.post(
    "/",
    upload.single("listing[image]"),
    wrapAsync(listingController.createListing)
);
When the request arrives, Multer separates the request into two parts.
Text fields
Everything except the file becomes:
req.body = {
    listing: {
        title: "Beach House",
        price: "2500"
    }
}
Uploaded file
The uploaded image becomes:
req.file = {
    fieldname: "listing[image]",
    originalname: "house.jpg",
    filename: "wanderlust_DEV/abc123",
    path: "https://res.cloudinary.com/...",
    mimetype: "image/jpeg",
    size: 245678
}
